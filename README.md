# MyMathTool

MyMathTool: A full feature-packed program that takes a basic calculator and makes it much more useful. With MyMathTool, you can plot graphs, do unit conversions, calculate financial data, run logic formulas through our logic gate evaluator, etc...

---

## Features
- Expanded standard calculator.
- Graphing tool that can graph exponentials, logarithms, sine waves, polynomials, etc.
- Logic gate evaluator.

---

## Tech Stack
- [C#](https://learn.microsoft.com/en-us/dotnet/csharp/) - WinForms
- [.NET](https://dotnet.microsoft.com/)

## Bugs
With MyMathTool being in early development, there are some bugs to be expected.
Some bugs that I am aware of are the following:
- Some calculations take too long or crash (Taking too long isn't necessarily a "bug", but it is annoying)
- Exponents may not always compute correctly.
